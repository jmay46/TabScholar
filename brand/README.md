# Brand artwork

`tabscholar-logo-source.png` is the original PNG supplied by the project owner
on September 1, 2026. The checked-in extension icons are square, transparent
exports of that exact artwork; they are resized but not redrawn.

Regenerate the 16, 32, 48, and 128 pixel extension assets on Windows with:

```powershell
npm run icons
```

Regenerate the 1280 × 640 GitHub social-preview image with:

```powershell
npm run social-preview
```

`NOTICE.md` for its separate rights notice.
